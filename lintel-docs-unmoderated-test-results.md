# Lintel Docs Unmoderated Test Results

## Summary

Results of the unmoderated test of Lintel Kit's getting-started page, 8 participants, 2026-08-24 to 2026-08-31.

## Key Details

- Task 1, install the kit into a new file: 6 of 8 succeeded; two missed the step that enables the library.
- Task 2, change the brand color token and see it on a button: 7 of 8. Median 4 minutes.
- Task 3, find guidance on text colors: 4 of 8. P1 and P2 had the faulty wording (a page that did not exist) and are excluded from that task; of the other six, 4 succeeded.
- Naming: 2 of 8 said "surface-raised" sounded like a shadow, not a background color.
- SUS 71 (8 participants), not very meaningful for a docs page.

## Why It Matters

Feeds the V2 docs rewrite and the token rename. The skipped pilot is the method lesson ([[unmoderated-testing]]).

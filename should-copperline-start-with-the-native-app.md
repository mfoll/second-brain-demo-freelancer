# Should Copperline Start With The Native App

Archived. Superseded on 2026-02-20 by [[copperline-responsive-first-decision-2026-02-20]].

Should the Copperline redesign start with the mobile app rather than the website, as a board member suggested at the discovery readout?

## What I thought in November 2025

Probably not, since 62% of sessions came from phone browsers ([[copperline-analytics-snapshot-2025-08]]), but the board wanted to see app concepts, so I proposed a short concept sprint to make the comparison concrete ([[copperline-native-app-concepts]]).

## How it was settled

Hollis Dunmore showed that the vendor app only exposes theming until its contract renews in 2027. The board chose responsive web first. The app question returns in 2027; it is not tracked as open until Copperline raises it.

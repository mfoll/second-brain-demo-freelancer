The prioritised fix list delivered with the Thistlewood audit, as a spreadsheet that Odette Fairweather now maintains.

## Key Details

- 74 rows, sorted by severity, then by who can fix it: configuration (Samir Haddadin's team), library templates, or vendor only ([[audit-severity-levels]]).

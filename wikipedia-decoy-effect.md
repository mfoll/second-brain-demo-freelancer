# Decoy effect

## Summary

The decoy effect is when adding a third, clearly worse option changes which of two other options people prefer. The decoy is "asymmetrically dominated": worse than one option on every attribute, but only partly worse than the other, so it makes the dominating option look better.

## Why It Matters

Read in September 2026 after Nadia asked, at the [[circle-proposal-review-2026-07-16]], whether my option C is a decoy. My answer: it shouldn't be. Option C in my [[proposal-template-2026]] is a real scope I'd happily deliver, not a worse deal planted to sell B. If I ever catch myself writing an option nobody should buy, I've crossed from [[three-option-proposals]] into manipulation.

## Key Details

- Works through comparison, not through the decoy being chosen.
- Strength of the effect varies a lot between studies.

## Caveats

Mostly consumer-choice research. Clients buying design services discuss options with colleagues, which probably weakens the effect.

# Thistlewood Screen Reader Test Log

My log of screen reader testing on the Thistlewood catalog, June 2025: NVDA with Firefox and Chrome on Windows, VoiceOver with Safari on macOS and iOS.

## Key Details

- Each test is a scripted task (search, filter, open record, place hold, check loans) run on each combination, with what was announced and what should have been.
- 18 of the 74 findings came from this log, including the unlabeled facets and the unannounced login errors.
- Differences between screen readers were smaller than expected; the failures were in the markup, not the reader.
- Time: 3 days of the 12.5. Slow because I was still learning NVDA shortcuts from the Sablewing course ([[accessibility-deep-dive-2025]]).

## Why It Matters

The scripted-task format is now part of [[run-an-accessibility-audit]]. Background on the tools in [[wikipedia-screen-reader]].

# Screen Reader Commands Cheat Sheet

The commands I actually use in audits, written during Sablewing module 4 in April 2025 and kept by my keyboard since. Desktop screen readers on two operating systems plus one phone screen reader.

- Start and stop speech; pause speech (the key I press most).
- Next and previous heading; heading level list.
- Next landmark; landmark list.
- Next form field; next button; next link; elements list.
- Read current line; read from here.
- Tab and Shift+Tab for focus order, separately from reading order.
- Phone: swipe right and left for next and previous; rotor or reading controls for headings; double tap to activate.

## Habits

- Turn speech rate down to the default before any session where a client watches.
- Test with the screen off for one pass per audit ([[screen-reader-testing]]).
- Log which screen reader and browser pair found each issue; behaviour differs.

Exact key bindings change with versions, so this sheet names actions, not keys. The keys are on the paper copy taped to my monitor.

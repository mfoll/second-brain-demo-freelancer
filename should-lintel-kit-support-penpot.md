# Should Lintel Kit Support Penpot?

Should I sell a Penpot edition of Lintel Kit alongside the Figma one?

## Current Answer

Deferred until after V2 and the team-license decision. Not before spring 2027.

## Evidence

- Demand: three of five refunds were Penpot users; four support emails asked. Small against 212 sales ([[lintel-sales-dashboard]]).
- Cost: Penpot's tokens import the same JSON format we already produce, so tokens are cheap; components must be rebuilt by hand. Estimate about 40 hours ([[penpot-design-tokens-docs]]).
- Maintenance: every release would be built twice, which breaks the four-hours-a-week rule ([[the-kit-must-not-eat-client-time]]).

## What would change it

Penpot requests doubling, or a Penpot user offering to maintain that edition for a share, the way [[jae-won-seo]] does the coded tokens.

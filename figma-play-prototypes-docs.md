# Play your prototypes

## Summary

Figma Help Center page on running prototypes, either inline in the editor (Preview) or in a separate presentation view (Present). It covers how frames and flow starting points decide what plays, the presentation toolbar and bottom bar (navigation, device switcher, restart), the options menu (hotspot hints, keyboard shortcuts, offline availability, Hide UI) and scaling choices such as Responsive, Fit width and Fixed size.

## Why It Matters

Checked three days before the [[velora-pitch-presentation-2026-05-14]], where I ran the unlock-flow concept live over a video call ([[velora-pitch-deck-and-prototype]]). Two settings mattered: hiding the UI so the panel saw only the phone, and starting from a named flow so I could jump straight to the error state when the engineering lead asked for it.

## Key Details

- Hide UI changes the prototype link; a link shared with it hides the interface for other viewers too. I sent the panel the normal link afterwards.
- Hotspot hints off for a pitch; on for usability tests.

## Caveats

Interface details change often; this describes the page as I read it in May 2026.

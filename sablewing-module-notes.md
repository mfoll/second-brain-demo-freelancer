# Sablewing Module Notes

## Summary

My own notes from the 12 Sablewing modules, about 60 pages in a notes app, exported to PDF when the course ended. Mostly worked examples and my mistakes, not course content.

## Key Details

- Module 2: contrast checks on real brand palettes; the lesson that a brand color can pass 3:1 for components and fail 4.5:1 for text, which I later used on Copperline ([[color-contrast-for-text]]).
- Module 4: my first screen reader week; the commands went into [[screen-reader-commands-cheat-sheet]].
- Module 8: status messages and live regions, the area I missed in the final.
- Module 11: report structure, the basis of my [[wcag-audit-checklist]].

## Caveats

Notes from 2025, against WCAG 2.2. Check against the W3C text before quoting a criterion.

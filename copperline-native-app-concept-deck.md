# Copperline Native App Concept Deck

Archived. The 22-slide deck from the native app concept sprint, presented on 2025-12-12. Superseded by [[copperline-responsive-first-decision-2026-02-20]].

## Summary

Four concept directions for the app home and transfer screens: "accounts first" (closest to the old app), "tasks first" (move money and pay as the home screen), "conversational" (a guided assistant for transfers) and "goals" (savings goals up front). Recommendation: tasks first, the same idea that later shaped the responsive web design.

## Why It Matters

Kept for two reasons. The tasks-first direction carried over into the web redesign, so the reasoning is still useful. And it is a reminder to check build constraints first: none of the four could be built inside the vendor's white-label app before 2027.

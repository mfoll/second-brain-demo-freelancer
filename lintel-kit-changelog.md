# Lintel Kit Changelog

The public changelog shipped with every release, summarised.

## Key Details

- **1.0** (2025-11-12): launch. 42 components, three variable collections, coded tokens in JSON and CSS.
- **1.0.1** (2025-11-28): focus-ring alias fixed after [[mirela-dobos]]'s report; build now fails on unresolved aliases.
- **1.1** (2026-03-02): spacing tokens renamed to a t-shirt scale with the old names kept as deprecated aliases; getting-started page rewritten; two buyer-reported bugs fixed.
- **1.2** (2026-05-06): nested component tokens fixed (reported by [[calvin-moyo]]); added a data-table row component; note on Figma plan requirements for publishing libraries.
- **2.0** (planned 2026-12-01): dark mode, contrast-checked color pairs, role-named accent tokens ([[lintel-kit-v2]]).

## Why It Matters

The release history buyers see. Deprecated aliases from 1.1 will be removed in 2.0, which the V2 notes must say clearly.

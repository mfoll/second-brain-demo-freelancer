# Answer Lintel Support Requests

Twice a week, Tuesday and Friday at 08:30, 30 minutes each. Release weeks: daily.

## Steps

1. Open the Lintel mailbox. Oldest first.
2. Setup or Figma plan question: answer with the matching getting-started section link plus one sentence. If the section did not exist, note it for the next docs update.
3. Color or contrast question: point to the pair and its allowed use; from V2, link the pairs page.
4. Coded tokens question: answer if it is about naming; forward build problems to [[jae-won-seo]] with the buyer's details removed.
5. Bug: reproduce in a blank file. If confirmed, thank the buyer, add it to the next release and log it.
6. License or invoice request: reply with the license terms. Team requests go to [[lintel-team-license-requests]]; no custom terms.
7. Log each request in the [[lintel-support-log]] with minutes spent.

## Guardrails

- Stop at 30 minutes; the rest waits until the next slot. Buyers are told replies take up to three working days.
- If the week passes four hours, note why ([[how-much-support-can-the-kit-take]]).
- Never ask for or accept access to a buyer's Figma files.

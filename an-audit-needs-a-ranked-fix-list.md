# An Audit Needs A Ranked Fix List

## Stance

An accessibility audit is only worth its fee if it ends in a ranked fix list that says how bad each issue is and who can fix it. A long report of failures by criterion gets shelved.

## Scope

Audits for organisations without an in-house accessibility specialist, which is all of mine so far.

## Why I Think This

- Thistlewood's fix list, with severity and an owner tag, became Odette Fairweather's vendor negotiation document; 19 of 31 critical and high issues were fixed in eight months ([[thistlewood-fix-list]]).
- Samir Haddadin went from skeptical to cooperative once the list separated configuration fixes from vendor defects.
- Reports I saw at Orchard & Vane, ordered by WCAG criterion, were rarely acted on.

## What Would Change My Mind

A client with a mature accessibility team who wants raw findings by criterion. Confidence is Medium because I have run only two audits independently.

## Implications

The fix list is the main deliverable, the report supports it. Tallowmere gets the same format ([[tallowmere-ticketing-audit]]).
